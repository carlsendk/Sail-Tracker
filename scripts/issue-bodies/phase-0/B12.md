### Goal

Add Playwright e2e wiring with one smoke spec that boots Next.js, hits `/`, and asserts a known piece of text.

### Context

This is the twelfth Phase 0 task. It is independent of B11 (RTL is component-level, Playwright is browser-level), but together they cover both ends of the UI testing stack. Future tier work will rely on this being available without setup.

### Embedded Spec

From `docs/plans/plan.md` § Phase 0 → Scope:

> Vitest + React Testing Library + Playwright wired up; coverage thresholds set

Per the Phase 0 issue table (row B12): files `apps/web/playwright.config.ts`, `apps/web/e2e/smoke.spec.ts`. Acceptance: `pnpm e2e` boots Next, hits `/`, asserts text; one e2e test passes locally.

### Files

- Create: `apps/web/playwright.config.ts` — `webServer.command = "pnpm dev"`, `webServer.url = "http://127.0.0.1:3002"`, `testDir = "e2e"`, retries=0 locally / 2 in CI, browsers chromium only initially
- Create: `apps/web/e2e/smoke.spec.ts` — navigate to `/`, assert visible text (e.g. heading or any deterministic copy currently on the home page)
- Modify: `apps/web/package.json` — add `e2e` script (`playwright test`); add `e2e:install` script (`playwright install chromium`); add dev dep `@playwright/test`
- Modify: `package.json` (root) — add an `e2e` pass-through script invoking `pnpm --filter web e2e`
- Modify: `.gitignore` — ignore `apps/web/test-results`, `apps/web/playwright-report`, `apps/web/.playwright`

### Acceptance Criteria

- [ ] `apps/web/playwright.config.ts` exists and uses Next's dev server via the `webServer` block
- [ ] `apps/web/e2e/smoke.spec.ts` exists, hits `/`, asserts a deterministic visible piece of content
- [ ] Running `pnpm --filter web e2e` (after `pnpm --filter web e2e:install`) passes locally
- [ ] `pnpm e2e` from the repo root works as a passthrough
- [ ] `.gitignore` excludes Playwright outputs
- [ ] CI hookup is NOT in scope here; B13 wires the CI job

### TDD Steps

1. Install `@playwright/test` in `apps/web`. Add scripts.
2. Author `playwright.config.ts` and the smoke spec.
3. Run `pnpm --filter web e2e:install` (one-time browser download); then `pnpm --filter web e2e`. Iterate until green.
4. Update `.gitignore` for Playwright outputs.
5. Commit `test(web): wire playwright + smoke spec`; PR `Closes #<this-issue>`.
