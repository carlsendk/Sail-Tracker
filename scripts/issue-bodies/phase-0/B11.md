### Goal

Wire React Testing Library + jsdom + `@testing-library/jest-dom` into the existing Vitest setup, then add a smoke test that renders the Next.js root page and asserts an h1.

### Context

This is the eleventh Phase 0 task. It is independent of the ESLint chain. The repo already runs Vitest on `apps/web` but has no DOM testing scaffolding — every product UI test we ship in later tiers depends on this being in place.

### Embedded Spec

From `docs/plans/plan.md` § Phase 0 → Scope:

> Vitest + React Testing Library + Playwright wired up; coverage thresholds set

Per the Phase 0 issue table (row B11): files `apps/web/package.json`, `apps/web/vitest.config.ts`, `apps/web/__tests__/smoke.test.tsx`. Acceptance: smoke renders `<Page/>`, asserts h1; jsdom + RTL + `@testing-library/jest-dom` working.

### Files

- Modify: `apps/web/vitest.config.ts` — set `environment: "jsdom"`, add a `setupFiles` entry pointing to a new setup file
- Create: `apps/web/vitest.setup.ts` — import `@testing-library/jest-dom`
- Modify: `apps/web/package.json` — add dev deps: `@testing-library/react`, `@testing-library/jest-dom`, `@testing-library/user-event`, `jsdom`
- Create: `apps/web/__tests__/smoke.test.tsx` — render the root page or a tiny `<Page>` shim and assert an h1

### Acceptance Criteria

- [ ] `apps/web/vitest.config.ts` sets `test.environment = "jsdom"` and includes the new setup file
- [ ] `apps/web/vitest.setup.ts` imports `@testing-library/jest-dom` (or `@testing-library/jest-dom/vitest` if version requires)
- [ ] `apps/web/__tests__/smoke.test.tsx` renders a real React component and uses RTL `screen.getByRole("heading", { level: 1 })` to assert
- [ ] `pnpm --filter web test` passes
- [ ] No existing test in `apps/web/tests/**` breaks
- [ ] If the root page (`apps/web/app/page.tsx`) does not currently render an h1, the smoke test renders a minimal shim that does — do not change product code in this issue

### TDD Steps

1. Install RTL + jest-dom + jsdom via `pnpm --filter web add -D @testing-library/react @testing-library/jest-dom @testing-library/user-event jsdom`.
2. Edit `apps/web/vitest.config.ts` to set `environment: "jsdom"` and `setupFiles: ["./vitest.setup.ts"]`. Create `vitest.setup.ts`.
3. Author `apps/web/__tests__/smoke.test.tsx` rendering a `<h1>Sail Tracker</h1>` shim; assert via `getByRole("heading", { level: 1, name: /Sail Tracker/ })`. Run → PASS.
4. (Optional) Try rendering the real root page (with mocks for any server-only imports). If it works without ceremony, switch the smoke test to that. Otherwise leave the shim and note in PR body.
5. Commit `test(web): wire RTL + jsdom; add smoke test`; PR `Closes #<this-issue>`.
