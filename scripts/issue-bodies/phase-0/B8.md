### Goal

Lint Markdown/MDX docs with markdownlint, spellcheck them with cspell, and check links — all enforced via `pnpm md:lint` and `pnpm cspell`.

### Context

This is the eighth Phase 0 task. It does not depend on the ESLint chain (B2-B6) — these are doc-tree quality gates, not source-code rules. Without them, docs accumulate broken links and inconsistent prose.

### Embedded Spec

From `docs/plans/plan.md` § Phase 0 → Scope:

> markdownlint + cspell + markdown-link-check on the `/docs` tree

Per the Phase 0 issue table (row B8): files `.markdownlint.jsonc`, `cspell.config.yaml`, `.markdownlintignore`. Acceptance: `pnpm md:lint` and `pnpm cspell` pass on existing docs. Coverage: `docs/**/*.md`, `**/*.mdx`, `README.md`; project dictionary committed.

### Files

- Create: `.markdownlint.jsonc` — extend default; relax MD013 (line length) and any other genuinely noisy rules
- Create: `.markdownlintignore` — ignore `node_modules`, `.next`, `apps/web/.next`, `pnpm-lock.yaml`, generated files
- Create: `cspell.config.yaml` — base dictionaries + custom dictionary file
- Create: `cspell-words.txt` — project dictionary (initially seeded from running cspell on the doc tree)
- Modify: `package.json` (root) — add scripts: `md:lint`, `md:link-check`, `cspell`; add dev deps for `markdownlint-cli2`, `cspell`, `markdown-link-check`
- Test: `pnpm md:lint`, `pnpm cspell`, `pnpm md:link-check`

### Acceptance Criteria

- [ ] `pnpm md:lint` runs over `docs/**/*.md`, `**/*.mdx`, `README.md` and exits clean
- [ ] `pnpm cspell` runs over the same scope and exits clean (project dictionary committed)
- [ ] `pnpm md:link-check` runs over the same scope and reports broken links (this may be a non-blocking script that lists offenders for now; document in the PR body if so)
- [ ] `.markdownlintignore` excludes node_modules, build output, lockfiles
- [ ] No file in `docs/` is excluded from lint without a recorded reason

### TDD Steps

1. Install `markdownlint-cli2`, `cspell`, `markdown-link-check`. Add `.markdownlint.jsonc` with defaults.
2. Run `pnpm md:lint`; iterate until clean (relax rules in config OR fix files; prefer fixing files).
3. Run `pnpm cspell` once; capture all reported unknown words to `cspell-words.txt`. Re-run → clean.
4. Run `pnpm md:link-check` to catch broken links; fix or note in PR body.
5. Commit `chore(docs): add markdownlint + cspell + link-check`; PR `Closes #<this-issue>`.
