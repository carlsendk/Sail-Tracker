### Goal

Replace the existing single-job `CI` workflow with a full pipeline whose jobs are named exactly `lint`, `typecheck`, `test`, `knip`, `dep-cruise`, `markdownlint`, `cspell`, `gitleaks`, `audit`, `e2e`. Add CodeQL and Dependabot.

### Context

This is the thirteenth Phase 0 task and the integration point for everything before it. After this lands, branch protection on `main` will be tightened (via `scripts/gh-bootstrap-branch-protection.sh`) to require all of these named status checks. The job names are load-bearing — they are referenced by branch protection.

### Embedded Spec

From `docs/plans/plan.md` § Phase 0 → Scope:

> CI workflow runs lint, typecheck, test, knip, dep-cruise, markdownlint, cspell, gitleaks, audit
> Branch protection on main requires the CI checks
> gitleaks + audit-ci + CodeQL for secrets, vuln, and security scanning in CI

Per the Phase 0 issue table (row B13): files `.github/workflows/ci.yml`, `.github/workflows/codeql.yml`, `.github/dependabot.yml`, `.gitleaks.toml`. Acceptance: PR shows all green checks; jobs named exactly `lint`, `typecheck`, `test`, `knip`, `dep-cruise`, `markdownlint`, `cspell`, `gitleaks`, `audit`, `e2e`.

### Files

- Modify: `.github/workflows/ci.yml` — replace single CI job with parallel jobs for each check above. Each job runs on `ubuntu-latest`, uses `pnpm/action-setup@v4` BEFORE `actions/setup-node@v6` (this is required — see `docs/plans/2026-05-07-agent-backlog-bootstrap.md` for prior CI bug)
- Create: `.github/workflows/codeql.yml` — schedule + on-PR CodeQL JS/TS analysis
- Create: `.github/dependabot.yml` — weekly npm + github-actions update PRs
- Create: `.gitleaks.toml` — base config (allow `examples/` etc. as needed)
- Modify: `package.json` (root) — add an `audit` script (`pnpm audit --audit-level high` or use `audit-ci`)
- Test: open a PR; observe all 10 status checks running and passing

### Acceptance Criteria

- [ ] `.github/workflows/ci.yml` defines 10 jobs whose `name:` (or job key) values match exactly: `lint`, `typecheck`, `test`, `knip`, `dep-cruise`, `markdownlint`, `cspell`, `gitleaks`, `audit`, `e2e`
- [ ] All jobs use `pnpm/action-setup@v4` BEFORE `actions/setup-node@v6` (do not reintroduce the corepack-enable step that previously broke)
- [ ] `e2e` job runs `pnpm --filter web e2e:install` then `pnpm --filter web e2e`
- [ ] `gitleaks` job runs `gitleaks/gitleaks-action@v2` (or invokes the binary directly)
- [ ] `audit` job runs `pnpm audit` at level high (or audit-ci configured equivalently)
- [ ] `.github/workflows/codeql.yml` exists and runs on PRs to main and on a weekly schedule
- [ ] `.github/dependabot.yml` exists and configures weekly `npm` (root) and `github-actions` updates
- [ ] `.gitleaks.toml` exists and the gitleaks job uses it
- [ ] PR for this issue completes with all 10 checks green

### TDD Steps

1. Author the new `.github/workflows/ci.yml` with all 10 jobs in parallel.
2. Author `codeql.yml`, `dependabot.yml`, `.gitleaks.toml`.
3. Open a draft PR to trigger CI; iterate on workflow YAML until all 10 jobs go green.
4. Once green, mark the PR ready for review.
5. Commit chain `ci: split into ten jobs`, `ci: add codeql + dependabot + gitleaks`. PR `Closes #<this-issue>`.
