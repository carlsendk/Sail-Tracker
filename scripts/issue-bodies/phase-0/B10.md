### Goal

Add knip (unused exports), dependency-cruiser (cycles + cross-layer enforcement at the build-graph level), syncpack (workspace-wide version pinning), and manypkg (monorepo health) — all wired into `pnpm` scripts.

### Context

This is the tenth Phase 0 task. These tools complement ESLint and TypeScript by analyzing the dependency graph and the workspace shape — things lint cannot see. dep-cruiser specifically gives us a second layer of architectural enforcement that runs on the actual import graph (vs. ESLint's per-file view).

### Embedded Spec

From `docs/plans/plan.md` § Phase 0 → Scope:

> knip + dependency-cruiser for unused-export and circular-dep detection
> syncpack + manypkg for monorepo dependency consistency

Per the Phase 0 issue table (row B10): files `knip.config.ts`, `dependency-cruiser.config.mjs`, `syncpack.config.mjs`. Acceptance: `pnpm knip` clean; `pnpm dep:cruise` rejects cycles; `pnpm syncpack list-mismatches` clean. Coverage: dep-cruiser rejects cross-layer + cycles; syncpack pins versions across `packages/*`.

### Files

- Create: `knip.config.ts` — entry points (apps/web pages, package barrels, scripts, configs); ignore patterns for generated code
- Create: `dependency-cruiser.config.mjs` — forbidden rules: cycles, cross-layer (mirroring B3's matrix), test-from-source, no-orphans
- Create: `syncpack.config.mjs` — pin versions across `packages/*`; allow apps to deviate where warranted
- Modify: `package.json` (root) — add scripts: `knip`, `dep:cruise`, `syncpack:list`, `manypkg:check`; add dev deps for `knip`, `dependency-cruiser`, `syncpack`, `@manypkg/cli`
- Test: each of the four scripts above

### Acceptance Criteria

- [ ] `pnpm knip` runs and reports unused exports/files (or zero — initial run; if it surfaces real issues, fix or document them)
- [ ] `pnpm dep:cruise` runs and rejects: import cycles, cross-layer imports per the B3 matrix
- [ ] `pnpm dep:cruise` returns clean on the current codebase (or only flags issues already discussed in PR body)
- [ ] `pnpm syncpack list-mismatches` returns clean
- [ ] `pnpm manypkg:check` returns clean
- [ ] Dependency-cruiser rule for cycles is enabled with severity `error`

### TDD Steps

1. Install dev deps. Add scripts to `package.json`.
2. Author `dependency-cruiser.config.mjs` with `no-circular`, `no-orphans`, and a layer rule that mirrors B3.
3. Run `pnpm dep:cruise`; resolve any real issues or refine config (justify in PR body).
4. Author `knip.config.ts`; run `pnpm knip`; resolve or justify.
5. Author `syncpack.config.mjs`; run `pnpm syncpack list-mismatches`; align versions.
6. Run `pnpm manypkg:check`; resolve.
7. Commit `chore(monorepo): add knip, dep-cruiser, syncpack, manypkg`; PR `Closes #<this-issue>`.
