### Goal

Establish formatting (Prettier), CSS linting (Stylelint), and editor configuration (EditorConfig) as workspace-level conventions enforced by `pnpm format:check` and `pnpm stylelint`.

### Context

This is the seventh Phase 0 task. It does not depend on the ESLint chain (B2-B6) because formatting runs separately from lint. It is, however, a prerequisite for B9 (lint-staged runs Prettier on commit). Without these, every contributor formats differently.

### Embedded Spec

From `docs/plans/plan.md` § Phase 0 → Scope:

> Prettier (formatting) and Stylelint (CSS) configured and enforced

Per the Phase 0 issue table (row B7): files `prettier.config.mjs`, `.prettierignore`, `stylelint.config.mjs`, `.editorconfig`. Acceptance: `pnpm format:check` and `pnpm stylelint` pass. Coverage: Prettier handles TS/MDX/JSON/YAML; Stylelint covers `*.css`.

### Files

- Create: `prettier.config.mjs` — base config (sane defaults; explicit only where we differ)
- Create: `.prettierignore` — node_modules, .next, build artifacts, lockfiles, generated files, `*.svg`
- Create: `stylelint.config.mjs` — extends `stylelint-config-standard` (or equivalent); add CSS Nesting + custom property rules as fits Tailwind/PostCSS layout
- Create: `.editorconfig` — utf-8, lf, indent_style/size matching Prettier, trim trailing whitespace, insert final newline
- Modify: `package.json` (root) — add scripts `format`, `format:check`, `stylelint`; add dev deps for Prettier, Stylelint, and any required configs
- Test: `pnpm format:check`, `pnpm stylelint`

### Acceptance Criteria

- [ ] `prettier.config.mjs` exists; `pnpm format:check` runs clean across the workspace
- [ ] `.prettierignore` exists and excludes lockfiles + build outputs + `*.svg`
- [ ] `stylelint.config.mjs` exists; `pnpm stylelint` runs clean over `**/*.css`
- [ ] `.editorconfig` exists and is consistent with Prettier output
- [ ] `package.json` exposes `format`, `format:check`, `stylelint` scripts
- [ ] Any pre-existing files re-formatted in this PR are committed in a single mechanical "format" commit (or noted in the PR body as such)

### TDD Steps

1. Add `prettier.config.mjs` + `.prettierignore`. Run `pnpm format` once across the repo (one-time normalization commit, separate from config commit).
2. Add `stylelint.config.mjs`. Run `pnpm stylelint`; iterate until clean.
3. Add `.editorconfig` matching Prettier defaults.
4. Add scripts; run `pnpm format:check` and `pnpm stylelint` → expect PASS.
5. Commit chain: `chore(format): apply prettier baseline`, then `chore(format): add prettier, stylelint, editorconfig`. PR `Closes #<this-issue>`.
